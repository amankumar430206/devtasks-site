Features

Everything you need.
Nothing you don't.

Built for developers who ship fast and hate context switching.

✏️
Inline task creation
Select any code, press a shortcut. Tasks are created exactly where you are, linked to file and line number.
🔗
File-linked navigation
Every task remembers where it lives. Click it, land there. No searching, no digging through tabs.
🔍
Review system
Move tasks through Open → Review → Done with keyboard shortcuts. Your own mini sprint board inside VS Code.
👥
Batch assignment
Multi-select tasks, assign to teammates pulled from your git history. Distribute work in seconds.
🌿
Git-based collaboration
Tasks live in your repo as structured comments. They version with your code, branch with your branches.
⚡
Zero overhead
No cloud account, no subscription, no context switch to a browser tab. Just your editor and your tasks.
How it works

From code to done
in five steps.

01
Select code → Create task
Highlight a line or block in any file. Hit ⌘T to open the task creation prompt. Type a title and confirm.
02
Review your task list
Open the DevTasks sidebar to see all tasks across your workspace, grouped by file or status.
03
Move to review
When a task is ready for review, right-click → Mark as Review. Status updates in the sidebar instantly.
04
Assign to a teammate
Select a task, type @ to pick from your git collaborators. Assignment gets saved to the task metadata.
05
Close it. Ship it.
Mark as Done. The task stays in history, linked to the commit that resolved it. Your future self will thank you.

Installation

Get running in 30 seconds.

Three ways to install. Pick your flavor.

Option 01
Download VSIX
Grab the latest release from GitHub and install it directly.
↓ Download .vsix
  • 1. Open VS Code
  • 2. Extensions → ··· → Install from VSIX
  • 3. Select the downloaded file
Option 02
Via Command Line
If you have the code CLI installed, one command does it.
code --install-extension devtasks.vsix
Restart VS Code once it completes.
Option 03
Dev Mode
Want to contribute or hack on it? Run it locally from source.
git clone https://github.com/amankumar430206/devtasks.git
cd devtasks
npm install
Then press F5 in VS Code to launch Extension Development Host.
